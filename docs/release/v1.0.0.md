# ClipPlayer v1.0.0 – SAC-orientierter Source-only Release

## Unterstütztes Artefakt

`ClipPlayer-source-1.0.0.zip` enthält ausschließlich PowerShell, XAML,
Dokumentation und Prüfsummen. Es enthält keine eigene EXE, DLL, MSI oder MSIX.
Der Player startet über den gültig Microsoft-signierten Windows-PowerShell-5.1-
Host und lädt ausschließlich mit Windows gelieferte WPF-/Media-Komponenten.

Der auf diesem SAC-erzwungenen Rechner gemessene Installationsweg ist ein lokaler
Checkout des Tags `v1.0.0` plus `scripts\install-script-player.ps1`. Ein Browser-
Download kann Mark-of-the-Web tragen und unter `RemoteSigned` abgelehnt werden.
Nicht `Unblock-File`, `ExecutionPolicy Bypass`, selbstsignierte Zertifikate oder
das Abschalten von SAC/Defender verwenden. In diesem Fall den Git-Checkout oder
einen organisatorisch signierten/freigegebenen Verteilweg benutzen. Abweichende
WDAC-/AppLocker-Skriptregeln können auch Source-only-Dateien sperren.

## Behobene Fehler

- Veraltete MediaFailed-/MediaEnded-Ereignisse können Wiedergabe und Auswahl
  nicht mehr zurücksetzen; Pause-/Restart-Rennen besitzen atomare Evidence-Gates.
- Ein vor `MediaOpened` pausierter Seek bleibt erhalten. `Start-PlayerPlayback`
  liefert exakt einen Player und keinen unbeabsichtigten Hashtable-Boolean.
- Ein natürlich beendeter 1-Sekunden-Track wird anhand des Dispatcher-Acks
  korrekt von fehlendem Autoplay unterschieden.
- Ordnerscan und Sortierung laufen außerhalb des WPF-Dispatchers, sind
  generationengesichert und behalten bei Bursts nur das letzte Ergebnis.
- Der Installer arbeitet mit geprüftem Staging/Swap/Rollback, bewahrt exakte
  Registry-Werttypen und überschreibt keine fremden Shared-Key-Änderungen.
- Test-, Coverage- und SAC-Wrapper synchronisieren Prozesshandles, unterscheiden
  Fehler/Timeout/SAC-Block und bewahren bei Soak-Fehlern begrenzte Log-Evidence.
